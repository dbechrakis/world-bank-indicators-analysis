# World Bank Indicators Analysis

Intro to Big Data final project (M.Sc. Data Science). Loads six World Bank indicators — GDP, inflation, exports (% of GDP), nuclear electricity production, renewable electricity production, and renewable energy consumption — into a SQLite database and analyzes patterns across regions and over time.

## Pipeline

1. Raw World Bank CSVs (Economy/ and Environment/ folders) are cleaned and reshaped from wide to long format.
2. Cleaned tables are loaded into `world_bank.db` (SQLite) via `sql.py`.
3. `Final_Project_v7.py` runs the full analysis: regional aggregation, correlation and covariance heatmaps by continent, boxplots of the last 10 years per indicator, time-series plots by region, and an outlier report.

## What's in this repo

- `Final_Project_v7.py` — main analysis script (cleaning, aggregation, visualization, outlier detection)
- `sql.py` — builds the SQLite database from the cleaned indicator CSVs

## Outputs (generated by the scripts)

- Correlation & covariance heatmaps per continent
- Time-series plots per region and indicator
- Boxplots of the last 10 years per indicator
- `outliers_report.csv`

Figures and the cleaned datasets are being added directly on GitHub as a follow-up upload.
